CSP 內容雜湊

只貼 script/style 標籤內的原始內容，不含標籤。保留空白、縮排與換行；計算時不會執行內容。外部檔案的 SRI 必須針對確切檔案內容計算，不能直接把網址拿來雜湊。

GOOGLE MAPS JAVASCRIPT API
不是 iframe？就不能只開 frame-src。
Maps JavaScript API 會在你的頁面載入腳本、插入樣式、取得圖磚並可能使用 Worker。它與嵌入式 iframe 地圖需要不同的政策。
  1. 優先評估 Google 官方的 nonce 嚴格政策；後端為每次回應產生新值，並提供給 script 與 style 元素。
  2. 確認實際使用的 Maps 功能、圖磚、連線、字型與 Worker 需求；依官方 CSP 指南與目標版本測試。
  3. 官方相容範例可能包含廣泛域名或 unsafe-eval；不可為了地圖顯示就宣稱同時滿足所有弱掃要求。
Google Maps JS 官方 CSP 指南 ↗
CSP HASH / SUBRESOURCE INTEGRITY
要保留行內程式碼，可以用雜湊。
  1. 貼入標籤內的確切內容，不含 script/style 標籤；支援 SHA-256、SHA-384、SHA-512。
  2. 把含單引號的 hash-source 加入有效的 script/style 指令，保持原內容的空白與換行不變。
  3. 若是外部 CDN 檔案，SRI 的 integrity 屬性與 CSP 是不同檢查；以確切版本檔案計算，並確認 crossorigin 與服務端 CORS。
Nonce 不適用 onclick/style 屬性。屬性 hash 需要 unsafe-hashes，仍有內容重用風險；建議先外移行內事件。

      
BEYOND CSP
弱掃也常看這些，但它們不是 CSP 指令。
OWASP 標頭指南 ↗
項目建議方向影響與驗證
Strict-Transport-Security完成 HTTPS 後評估 HSTS先盤點 HTTPS 覆蓋與憑證；includeSubDomains/preload 影響所有涵蓋站點，不能隨意加入。CSP 升級請求不能取代 HSTS。
X-Content-Type-Optionsnosniff確保 JS/CSS 的 MIME 正確，否則可能被拒絕載入。
Referrer-Policy評估 strict-origin-when-cross-origin兼顧跨站來源識別與路徑隱私；no-referrer 可能影響 YouTube 識別或 Google Maps API key 驗證。
X-Frame-Options依需要設定 DENY 或 SAMEORIGIN以 frame-ancestors 為現代主要控制並評估舊瀏覽器；合作站嵌入需檢查相容性，不使用已過時的 ALLOW-FROM。
Cookie 屬性Secure、HttpOnly 與適當 SameSite依 Cookie 用途與跨站登入／iframe 流程測試；SameSite=None 需 Secure，也不能保證第三方 Cookie 被允許。
Permissions-Policy依需求限制相機、麥克風、定位等逐項盤點網站與 iframe 使用的能力；不能一律禁止後期待影音或地圖功能完全不受影響。
此處僅提供部署檢查方向，不會把以上內容混入 CSP。最終須在主機、反向代理或 CDN 設定 HTTP 回應；GitHub Pages 靜態檔案本身無法任意設定回應標頭。

01
盤點與保留退路
匯出目前的 JSON 專案，備份伺服器或 CDN 原有標頭。盤點第三方腳本、API、字型、iframe、付款與登入流程。
02

選擇觀察模式，將設定加到文件的 HTTP 回應。開啟開發者工具 Network 確認最終標頭，Console 查看違規。
若需集中回報，設定 report-to、Reporting-Endpoints 與實際接收服務，並送出測試事件。
03
測完整操作路徑
涵蓋登入／登出、搜尋、上傳預覽、表單、付款、影片、列印、行動版與不同瀏覽器。將合法需求加入精確來源；不要一律以 * 或 unsafe-inline 排除錯誤。
04
小範圍強制，再持續觀察
在測試環境或少量流量使用強制模式，確認後再擴大。出問題時回復原標頭或改回 Report-Only，並確認 CDN 快取已更新。
sandbox 與 upgrade-insecure-requests 的影響無法靠 Report-Only 完整預演，需另外測試。

你看到的現象優先檢查處理方向

LEARN BY DOING
不只產生一串字，也知道它代表什麼。
CSP 是瀏覽器執行的額外防線；它不會清理輸入，也不能取代修補 XSS、權限控制或安全的程式碼。

      
基本觀念
每個指令，是一類資源的規則
default-src 'self';
img-src 'self' https://images.example;
object-src 'none';
一般資源先參考 default-src；圖片因為另外指定 img-src，會使用自己的完整名單。none 代表不允許這類資源，self 指同協定、網域與連接埠。
不是所有指令都會回退。frame-ancestors、base-uri、form-action 必須另外設定。
常見混淆
載入別人，與被別人嵌入
你的網站→外部 iframeframe-src
別人的網站→你的頁面frame-ancestors
允許你載入影片，不代表允許別人嵌入你的網頁。frame-ancestors 要檢查完整祖先鏈，且只能透過 HTTP 標頭設定。
行內程式碼
self 不會允許行內腳本
同源 app.js 可以符合 self，但直接寫在 HTML 的 script、onclick 或 eval() 是不同的檢查。
Nonce：後端每次回應產生不可預測的新亂數，同時放進政策與 script/style 的 nonce 屬性。不能把產生器的固定值貼上永久使用。
Hash：授權完全相同的片段；任何空白改動都需要重新計算。外部 script 還涉及 integrity 與支援度。
部署差異
觀察模式不會提供強制防護
Content-Security-Policy-Report-Only 讓你在不強制擋資源的情況下收集違規，適合改版前盤點。確認後改為 Content-Security-Policy 才會封鎖違規行為。
同一網站可同時觀察一份新政策並強制既有政策；本工具一次編輯其中一份。sandbox 不支援 Report-Only；meta 也不支援觀察模式。

      
CLASSROOM EXERCISE
